# Local Schema Generator

Static, client-side generator for LocalBusiness JSON-LD (MIT). Open `index.html` or use the hosted version: https://tommytbomar-dot.github.io/tools/local-schema/

- `schema.js` — UMD core (browser + node), `node --test test`
- Nothing is uploaded; there is no backend.
